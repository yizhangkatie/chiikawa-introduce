# ちいかわ紹介サイト 

このサイトは、ナガノ先生による人気漫画作品「ちいかわ（なんか小さくてかわいいやつ）」を紹介するウェブサイトです。

## 制作目的 
このプロジェクトは、自分のフロントエンド開発スキルの向上を目的とした練習用サイトです。
主に以下の技術の実践を目的として制作しました。
- **Next.js** 
- **Tailwind CSS** 
- **Framer Motion**

## 公開URL 
こちらから実際のウェブサイトをご覧いただけます：
[https://chiikawa-ten.vercel.app/]
